# Как пользоваться проектом

В проекте выполнены четыре алгоритма на Java, тесты, замеры, CSV, графики и отчёт README на английском языке.

1. Открой папку проекта в IntelliJ IDEA как Maven-проект или используй терминал с JDK 17+.
2. `sh run.sh demo` — пример работы всех алгоритмов.
3. `sh run.sh test` — автоматические проверки; ожидается ALL TESTS PASSED.
4. `sh run.sh experiment` — повторить эксперименты (CSV будут перезаписаны).
5. README.md — полный отчёт с анализом рекуррентностей, таблицами, графиками и обсуждением.

Median-of-Medians использует нумерацию k с нуля: k=0 — минимум, k=n-1 — максимум. Поиск ближайшей пары возвращает расстояние.

Ссылка для сдачи: https://github.com/whoisaii/daa-a1 . В архив включена скрытая папка .git с историей разработки: не удаляй её. Исходный коммит GitHub сохранён; версия готового задания отмечена тегом v1.0.

Раздел Reflection содержит техническую рефлексию о проекте: отредактируй её под собственный опыт. Результаты замеров реальные, но могут отличаться на другом компьютере.
